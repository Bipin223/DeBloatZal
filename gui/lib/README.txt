Microsoft.Web.WebView2 1.0.4314.35 (net462)
=========================================

These three DLLs are bundled so the Debloater GUI needs no installer:

  Microsoft.Web.WebView2.Core.dll
  Microsoft.Web.WebView2.WinForms.dll
  WebView2Loader.dll

The actual Chromium engine is the Microsoft Edge WebView2 runtime that ships
with Windows 10/11. Only the small .NET wrapper is stored here.

Source: https://www.nuget.org/packages/Microsoft.Web.WebView2
